# 🎮 Tic-Tac-Toe Game

A classic **Tic-Tac-Toe game built using HTML, CSS, and JavaScript**. This project brings the traditional two-player game to the web with an interactive game board, player turn management, and automatic winner detection.

The project demonstrates fundamental frontend web development concepts, including DOM manipulation, event handling, conditional logic, and interactive user interface development.

## ✨ Features

* 🎯 **Interactive Game Board** – Play on a classic 3×3 grid.
* ❌⭕ **Two-Player Gameplay** – Players take turns using X and O.
* 🏆 **Win Detection** – Automatically detects winning combinations across rows, columns, and diagonals.
* 🤝 **Draw Detection** – Identifies when the game ends without a winner.
* 🔄 **Restart Game** – Reset the board and start a new match.
* 🎨 **User-Friendly Interface** – Simple and intuitive design.
* ⚡ **Real-Time Interaction** – Updates the game state after each move.

## 🛠️ Technologies Used

* **HTML5** – Creates the structure of the game.
* **CSS3** – Styles the game board and user interface.
* **JavaScript** – Implements the game logic, player turns, and result detection.

## 🎮 How to Play

1. Open the game in your web browser.
2. Player X takes the first turn.
3. Player O takes the next turn.
4. Players select empty cells on the 3×3 board alternately.
5. The first player to align three matching symbols horizontally, vertically, or diagonally wins.
6. If all cells are filled without a winner, the game ends in a draw.
7. Use the restart option to begin a new game.
